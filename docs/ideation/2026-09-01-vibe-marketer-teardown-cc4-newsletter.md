# The Vibe Marketer teardown + cc4.marketing newsletter plan

Source: 50 issues in mtri.vo@gmail.com (`from:thevibemarketer@mail.beehiiv.com`, Mar-Aug 2026). Read in full: Aug 25 roundup, Aug 27 essay, Aug 18 monetized recap. Subject lines scanned for all 50.

## Part 1: How The Vibe Marketer works

### Cadence
2 issues/week (lands Tue + Thu-ish, 4:00-4:07 AM VN time, so a fixed US send hour). Occasional 3rd send for live-session alerts.

### 5 recurring formats (the whole system)
1. **Builds roundup**: "4 builds, experiments, and discoveries to steal from this week". Community members' builds, each named and linked. Runs every week.
2. **POV essay / deep dive**: one thesis argued end to end ("AI play for local businesses is grow revenue, not headcount"). Anchored in the author's own business ($9k/day diesel repair) for proof.
3. **Session recap + product**: distills a free community session into 6 takeaways, then sells the $199 course built from it. Free value first, paid asset last, with disclosure.
4. **Live session alert**: short promo, named guest, date, one outcome promise.
5. **Case study**: a reader's result with hard numbers ("$150K. 125 orders. Brandon built his business off my playbook.").

### Fixed skeleton, every single issue
- Date + "Read online" link
- H1 repeats the subject, then a one-line dek (doubles as preheader)
- "Hey Vibe Marketer," + 2-4 line hook (question or contrarian claim)
- Body: short paragraphs, one idea per line, heavy use of 2-3 column tables to compress lists
- Per-item payoff line: "The idea to steal: ..."
- "Miscellaneous vibes": 7 curated links, lowercase casual titles
- "Let's vibe": 4-line CTA ladder, each line "Wanna X? → product" (audit tool, AI upgrade, community, bundle)
- "Just hit reply. I read every message." + share ask
- 3-option feedback poll (Premium Vibes / Kinda Vibes / Not the vibe)

### Copy patterns worth stealing
- Subjects = specific outcome + number: "$999 assessment into $8K retainers", "25k followers, 45M impressions", "3,200 pages". Or contrarian: "AI agents aren't enough", "You built a workflow, not a system".
- Formula chains as prose: "More demand → more customers → more intelligence → better decisions".
- Tables replace bullet walls. Every concept gets a 2-col "what happens / what it means" table.
- Community members featured by name with links. Free flywheel: readers submit builds to get featured, features fill the roundup.
- Every issue ends at the same product ladder. Monetization is structural, not occasional.

### Flywheel
Live sessions → recaps → paid courses. Community builds → roundup content. Newsletter → LinkedIn repurposing (they wrote an issue about exactly this). Own businesses → case-study material.

## Part 2: cc4.marketing adaptation

Positioning gap they leave open: they cover all AI marketing tools; cc4 owns one wedge, Claude Code for marketers. Every issue maps to a lesson, skill, or repo the reader can run today. That specificity is the differentiator, keep it.

### Recommendation
- **Cadence**: start 1x/week (Tue), alternate two formats. Add Thu only when backlog of community builds exists.
  - Week A: deep dive tied to a course module or skill (existing blog drafts are seeds: book-publisher, service-package, merge-campaign case study).
  - Week B: "4 workflows to steal" roundup: student builds, new skills in the course repo, changelog highlights, one external discovery.
- **Skeleton to clone** (rename, same bones):
  - Greeting: "Hey marketer," or a named reader identity (pick one and keep it)
  - Hook, body with tables, per-item "Steal this:" line
  - "Worth your tab space": 5-7 curated links (their "Miscellaneous vibes")
  - CTA ladder, cc4 version:
    - Wanna learn the workflows? → Start the free course (`/start-0-0`)
    - Wanna see what changed? → Changelog
    - Got a build to show? → Reply, best ones get featured
    - Wanna support the course? → Donate (VietQR block already built)
  - Reply prompt + share ask + 3-option poll (beehiiv/Resend both support polls or link-click voting)
- **Content sources already in repo**: 19 lessons, CHANGELOG.md, docs/blog-drafts, 4 past newsletter HTMLs in emails/, student replies. Session-recap format activates later if live sessions ever run.
- **Infra**: keep Resend + existing emails/ HTML pipeline (resend-email-campaign skill, subscriber-sync-repair plan). Build one reusable HTML template with the fixed skeleton so each issue is content-only. beehiiv migration only if referral program / web archive becomes a priority.
- **Bilingual**: keep EN primary. VN variant (precedent: 2026-07-22 -vi.html) only for issues with VN-specific hooks, not every send.
- **Feature-the-reader loop**: end every issue asking for builds. Feature 1 reader per roundup with name + link. This is their growth engine and costs nothing.

### First 4 issues (starter calendar)
1. Essay: "You finished the course. Now what?" (system vs workflow angle, mirrors their strongest essay theme)
2. Roundup: 4 workflows from the course repo (book-publisher, seo-audit, publish-post, one student build)
3. Case study: merge-campaign case study draft reworked with numbers up front in subject
4. Roundup: changelog quarter recap + 2 external discoveries + reader build

### Subject-line rules (from their 50)
Number + outcome beats topic. "How I/we + result" beats "Tips for". Contrarian negation works ("X isn't enough", "You don't need Y"). Keep under ~65 chars.
